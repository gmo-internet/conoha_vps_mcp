# 📦 MCP App: オブジェクトストレージ UI 利用ガイド

ConoHa VPS のオブジェクトストレージを GUI で操作できる MCP App（埋め込み HTML UI）の使い方を説明します。

LLM に自然言語で指示する代わりに、ブラウザ感覚でコンテナ・オブジェクトを直接操作できます。

---

## ✨ できること

| 操作 | UI 上の動作 | 内部で呼ばれる MCP ツール |
|---|---|---|
| コンテナ一覧表示 | ストレージタブを開く | `list_containers` |
| コンテナ新規作成 | `+ コンテナ作成` ボタン → 名前入力 | `create_container` |
| コンテナ削除 | コンテナカードホバー → `削除` | `delete_container` |
| オブジェクト一覧表示 | コンテナカードをクリック | `list_objects` |
| オブジェクトアップロード | `📤 ファイルをアップロード` → ファイル選択 | `upload_object` |
| オブジェクト削除 | オブジェクト行の `削除` | `delete_object` |

> 💡 オブジェクトのアップロードは **10 MB が上限**です。それ以上のファイルは `conoha_post_put` ツール経由（CLI / LLM）を利用してください。

## 🚀 セットアップ

### 1. 環境変数を設定

`.env` または Claude Desktop / Claude Code の MCP 設定で、ConoHa の API ユーザー情報を設定します。

```env
OPENSTACK_TENANT_ID=your-tenant-id
OPENSTACK_USER_ID=your-user-id
OPENSTACK_PASSWORD=your-password
```

ConoHa コントロールパネル → **API → APIユーザー** で確認できます。

### 2. （任意）動作確認だけしたい場合

実 API を呼ばずモックフィクスチャで UI を試したい場合:

```env
CONOHA_MCP_MOCK=1
```

→ サンプルのコンテナ・オブジェクトが表示されます。

### 3. MCP クライアントから起動

`list_containers` ツールを呼び出すと、Claude Desktop / 対応クライアント上で MCP App UI が開きます。

```
list_containers を実行してオブジェクトストレージを開いて
```

## 🖥️ 画面構成

### コンテナ一覧画面

```
┌──────────────────────────────────────────────┐
│ ConoHa VPS / storage              [MCP App] │
├──────────────────────────────────────────────┤
│ [ストレージ]                                  │
├──────────────────────────────────────────────┤
│ コンテナ 3 件             [+ コンテナ作成]     │
├──────────────────────────────────────────────┤
│ ┌────────────┐  ┌────────────┐               │
│ │📦 backups  │  │📦 media    │               │
│ │ 24 / 4.5GB │  │ 142 / 12GB │               │
│ │ 2026-04-20 │  │ 2026-04-22 │               │
│ └────────────┘  └────────────┘               │
└──────────────────────────────────────────────┘
```

- カードをクリック → そのコンテナのオブジェクト一覧へ
- カードにホバー → 右上に `削除` ボタンが現れる

### オブジェクト一覧画面（コンテナ詳細）

```
┌──────────────────────────────────────────────┐
│ ConoHa VPS / storage / backups   [MCP App]  │
├──────────────────────────────────────────────┤
│ [← 戻る] 📦 backups 2 件 [📤 アップロード]    │
├──────────────────────────────────────────────┤
│ 🗜️ db-2026-04-01.tar.gz                     │
│   ╭──────────╮                              │
│   │application/gzip│  2026-04-01  1.5 GB [削除]│
│   ╰──────────╯                              │
│ 🖼️ hero.jpg                                 │
│   ╭──────────╮                              │
│   │image/jpeg│  2026-04-22  2.4 MB [削除]    │
│   ╰──────────╯                              │
└──────────────────────────────────────────────┘
```

各オブジェクト行の表示:
- 🖼️ MIME 種別アイコン
- ファイル名 + MIME バッジ（cyan）
- 更新日（YYYY-MM-DD）
- 容量（B / KB / MB / GB / TB に自動整形）
- 削除ボタン

### コンテナ作成画面

`+ コンテナ作成` を押すとフォームが表示されます。

- 名前は **英数字 / ハイフン / アンダースコア / ピリオド** のみ使用可能（スラッシュ不可）
- リアルタイムバリデーションで入力中に正規表現チェック
- `キャンセル` で一覧に戻る

### 削除確認モーダル

コンテナ・オブジェクトの削除はモーダルで確認:
- コンテナ削除時は「空でないコンテナは削除できません」の警告が表示されます（中身を先に空にしてください）

## 🛠️ トラブルシュート

### UI が開かない
- `list_containers` ツールに `_meta.ui.resourceUri` が設定されていることを確認（`src/apps/apps-tools.ts`）
- Claude Desktop の場合は最新版を利用しているか確認

### コンテナの容量が 0 のまま更新されない
- アップロード直後は ConoHa Swift の集計遅延で数秒〜十数秒かかることがあります
- 一度コンテナ一覧へ戻り、再度コンテナを開き直すと反映されます

### アップロードが「サイズ上限を超えています」で失敗する
- UI からは 10MB が上限です
- 大容量ファイルは `conoha_post_put` ツール経由（LLM 指示）で `path/to/file` を指定してアップロードしてください

### コンテナを削除できない（409 Conflict）
- Swift は空でないコンテナを削除できません
- 中身のオブジェクトをすべて削除してから再度コンテナを削除してください
